# Prime spiral as afterimage and memory path

**Status:** proposed representational model; definitions are exact once the encoding choices are fixed. It is not a theorem that prime numbers physically trace a spiral, nor that a plotted pattern explains prime distribution.

## 1. Three layers: sequence, path, afterimage

Let \(p_n\) be the \(n\)-th prime, indexed from \(n=1\). The prime sequence is the data. A spiral is one way to place that ordered data in a plane. An afterimage is a retained field generated by the points already visited.

Choose an angular increment \(\omega\) and an index-radius scale \(a>0\). Define

\[
\theta_n=n\omega\pmod{2\pi},\qquad r_n=an,
\qquad z_n=r_ne^{i\theta_n}.
\]

The plotted point \(z_n\) is labeled by \(p_n\). This is an **index spiral**: equal index steps give equal radial increments, while the prime values remain the labels. The geometry comes from the chosen encoding, not from a theorem about primes.

A different display may use \(r_n=\log p_n\), or \(r_n=p_n\). Those are different coordinate choices and can make different visual features prominent. They must not be silently interchanged.

## 2. The memory path

The path is the ordered record

\[
H_N=((1,p_1), (2,p_2),\ldots,(N,p_N)).
\]

A retained memory state may be a compressed or filtered part of that history:

\[
M_{N+1}=\operatorname{Update}(M_N,(N+1,p_{N+1})),
\qquad M_N\subseteq H_N
\]

when memory literally stores a subset; for a summary or feature vector, \(M_N\) is instead a function of \(H_N\), not a subset.

To connect prime arithmetic to the memory path, record the prime gap

\[
g_n=p_{n+1}-p_n
\]

and, when a matrix \(A\) has been specified, its prime-indexed spectral fingerprint \(\sigma_A(p_n)\). The augmented record can be

\[
h_n=(n,p_n,g_n,\sigma_A(p_n)).
\]

The spectral component is optional and depends on the chosen matrix and finite-field profile. It is not an intrinsic property of a prime alone.

## 3. The afterimage

An afterimage is a weighted accumulation of earlier path points. For a spatial kernel \(K\) and nonnegative memory weights \(w_j\), define

\[
\mathcal A_N(z)=\sum_{n=1}^{N}w_{N-n}K(z-z_n).
\]

- If \(w_j=1\), the afterimage is a persistent cumulative trace.
- If \(w_j=\lambda^j\), with \(0<\lambda<1\), older points fade exponentially.
- If \(w_j\) has finite support, the afterimage is a finite-window memory.

A corresponding feature afterimage can retain arithmetic observations rather than spatial points:

\[
\mathcal S_N=\sum_{n=1}^{N}w_{N-n}\,\phi(h_n),
\]

where \(\phi\) is an explicitly chosen feature map. This is a summary, not a reversible record unless \(\phi\) and the storage scheme preserve enough information.

## 4. Recurrence is not erasure

A spiral can revisit a similar angle or local configuration without revisiting the same state. Write

\[
z_{n+k}\sim z_n
\]

only after specifying a structural equivalence \(\sim\), such as equal angle modulo a tolerance, similar normalized local gap patterns, or equal spectral-profile classes.

Even if a geometric configuration recurs, the history generally differs:

\[
H_{n+k}\ne H_n.
\]

This is the memory-path version of the distinction between a circle's exact return and a spiral's structural return. The present state can resemble an earlier state while carrying a longer afterimage.

## 5. What the model can test

For a fixed angular increment and radius rule, one can test:

1. sensitivity of apparent clusters to \(\omega\), radial scaling, and plotting window;
2. whether local prime-gap features recur under a stated equivalence;
3. whether a chosen spectral fingerprint \(\sigma_A(p_n)\) adds information beyond prime gaps or residue classes;
4. how cumulative, fading, and finite-window afterimages differ;
5. whether a visual pattern survives changes of encoding and comparison against randomized or arithmetic baselines.

A pattern that disappears under a modest change of coordinates is likely an encoding artifact. A pattern that survives several controls is a candidate empirical regularity, not automatically a proof or explanation.

## 6. Interpretation limits

- The primes are the underlying arithmetic sequence; the spiral is a visualization of an ordered encoding.
- The afterimage is a defined memory operator; it is not a claim that primes retain physical memory.
- A spectral fingerprint is relative to the selected matrix, prime, and quantization convention.
- Visual recurrence does not prove periodicity of primes.
- The model does not derive the prime number theorem, the Riemann hypothesis, or a new prime law.

The central formulation is:

\[
\boxed{\text{prime data}\ \longrightarrow\ \text{encoded spiral path}\
\longrightarrow\ \text{retained afterimage}}
\]

The spiral shows where the sequence has been placed; the memory path preserves order; the afterimage makes prior positions or features continue to influence the present representation.
