# Applying the Fold to problems and conjectures

## Purpose and rule

This note turns the problem map into a working programme. The Fold is not treated as a universal solver. Each application must identify (i) the original mathematical object, (ii) the exact Fold object or operation, (iii) the theorem that transfers, and (iv) the premise or estimate that is still missing.

The four labels remain strict:

- **exact**: the Fold object is the problem's object, merely re-described;
- **reformulation**: an equivalent statement is obtained, but no new proof follows;
- **rhyme**: a useful structural analogy with different mathematical objects;
- **false friend**: a shared symbol or shape conceals a different object.

A conjecture is not advanced merely by receiving a Fold vocabulary.

## 1. A reusable theorem: operation quotients

Let a set (X) carry a chosen family of admissible operations (T_i:X\to X). Let \(\sim\) be the equivalence relation generated by the operation edges (including reversals and finite chains). Then:

1. every function (f:X\to Y) invariant under every (T_i) is constant on \(\sim\)-classes;
2. it therefore factors uniquely through the orbit quotient (X/{\sim});
3. the quotient is the **complete invariant** for the chosen operations: two states have the same quotient class exactly when the operations connect them.

This is the universal-property result recorded in `the-fold-universal-invariant.md`. It is exact, but conditional on the operation family. Change the allowed operations and the quotient changes. If all positive power operations are admitted on the finite spectral state space, the unoriented observable quotient can collapse to a single class. Thus “invariant” always means invariant under a specified action, not invariant under every imaginable transformation.

### Finite spectral-power application

For a finite family of positive exponents (R=\{r_1,\ldots,r_s\}), put (L=\operatorname{lcm}(R)). The previously derived invariant
\[
I_R(S)=\big((\operatorname{core}_L(d_j),\widehat\tau_L(\tau_j))\big)_j
\]
is complete for the abstract state graph generated by those powers and the allowed turn. Here `core` retains precisely the prime-power components whose primes do not divide (L); the turning coordinate is retained only when (L) is odd. This is a theorem about the abstract spectral-signature graph, **not** a prime-identification theorem, a prime-generation algorithm, or a zero-location result.

The application test is now concrete: before proposing a new spectral invariant, specify the operation family and compare the proposed invariant's fibers with the orbit classes. If the fibers are larger, it loses information; if smaller, it is not operation-invariant.

## 3. A concrete negative result: Collatz is not a homothety

Define the usual Collatz map (C:\mathbb N_{>0}\to\mathbb N_{>0}) by
\[
C(n)=\begin{cases}
n/2,&n\text{ even},\\
3n+1,&n\text{ odd}.
\end{cases}
\]

A Fold-style homothety about a datum (p) has the form
\[
g_k(n)=p+k(n-p).
\]
For (k\ne0), this map is injective; for (k=0), it is constant. The Collatz map is neither: it is nonconstant, while
\[
C(1)=4=C(8),\qquad 1\ne8.
\]
Therefore **no single affine homothety (g_k) agrees with (C)** on the positive integers.

This is a small but exact obstruction. It prevents the expansion/contraction rhyme from being promoted into a conjugacy or a one-parameter scale model. The right Fold application must retain the parity branch as part of the state. A candidate quotient should be tested against the directed graph of the actual Collatz map and must not identify states merely because they have the same scale exponent.

## 4. A proof-obligation template for every new conjecture

For each proposed application, fill these obligations in order:

1. **Object:** write the original object and its domain (operator, measure, group action, PDE, arithmetic sequence, or category).
2. **Operation:** specify the exact Fold operation on that domain. If it is piecewise, retain the branch label.
3. **Invariant:** prove invariance under every allowed operation.
4. **Completeness:** determine whether equal invariants are equivalent to belonging to the same operation orbit.
5. **Information loss:** identify what the quotient forgets. Compare that loss with the quantity the conjecture asks to determine.
6. **Missing premise:** state the external theorem, estimate, positivity, compactness, or construction still required.
7. **Certificate:** give a proof, counterexample, formal Lean statement, or reproducible exact computation. A numerical match is not a certificate of a universal claim.

A proposed bridge fails if it cannot pass steps 2–5. This is the practical filter that separates an exact application from a suggestive analogy.

## 5. Priority order

1. **Finish the exact algebraic frontier UF-072Q.** Construct a symbolic dual functional (\lambda) with (\lambda M=0) and (\lambda v\ne0), or prove the bounded ansatz cannot work. The three finite-field specializations are lower bounds only; no separation theorem is claimed yet.
2. **Formalize the operation-quotient theorem.** The abstract theorem is proved in the research note, but the Lean 4 implementation targets there are specifications, not compiler-verified code. Formalize reachability, invariance, and unique descent in a dependency-free module.
3. **Apply quotient completeness to concrete finite dynamics.** Collatz is a deliberately hard test because it is piecewise and non-injective. Begin with finite residue/valuation quotients and state precisely what each quotient forgets; do not infer global termination from finite cycles. The accelerated valuation analysis now excludes nontrivial periods through fifteen; the cycle note also now contains nested 3-adic suffix congruences for arbitrary period and a CRT filter on the minimum cycle member, with exact finite certificates for the remaining admissible valuation words; this is still not a global termination proof. The minimum cycle element is congruent to 3 modulo 4, yielding the uniform average-valuation window \(\log_2 3<A/p\le\log_2(10/3)\).
4. **Choose one analytic RH route and attack its missing premise.** The most Fold-native route is the de Bruijn–Newman heat flow, but the actual target is a sharp upper bound on (\Lambda), not another derivation of the central symmetry.
5. **Keep the other Millennium-problem contacts as boundary tests.** For BSD, Hodge, Yang–Mills, Navier–Stokes, and P vs NP, first construct the missing arithmetic, cycle, operator, PDE, or complexity object. Without it, the Fold contact remains a reformulation or rhyme.

## Conclusion

The Fold has one general exact strength: it identifies the quotient of a specified family of operations and therefore the information that survives those operations. Its applications become mathematically useful when the operation family is the problem's actual operation and the quotient retains the quantity at issue.

The Collatz test demonstrates the discipline: a global scale analogy is false as a model, while a branch-aware quotient remains a legitimate research direction. For RH, the crease is exact but the forcing estimate is still absent. For finite spectral powers, the complete quotient is already known. These are different statuses, and the research programme should preserve that difference.
