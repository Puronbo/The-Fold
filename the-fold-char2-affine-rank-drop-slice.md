# UF-062A — Exact rank-drop locus on a triangular affine slice

## 1. Setup

Work in characteristic two with
\[
A=k[x,z]/(x^4,z^2),\qquad
T=k[c,d,h]/(c^4,d^2,h^2).
\]
Use the seven-parameter subgroup
\[
u(x)=x+Ax^2+Bx^3+Cxz+Dx^2z+Ex^3z,
\]
\[
u(z)=z+Axz+Gx^3+(B+G)x^2z+Jx^3z.
\]
Restrict the affine conjugating automorphism to
\[
g(x)=x+c,\qquad g(z)=z+d+hx.
\]
The inverse is
\[
g^{-1}(x)=x+c,\qquad g^{-1}(z)=z+d+hx+hc.
\]
Using the correct algebra-map composition order,
\[
(gug^{-1})(x)=g(u(x))+c,\qquad
(gug^{-1})(z)=g(u(z))+d+h\,g(u(x))+hc.
\]

Expand the sixteen target coefficients
\[
(c',a',b',\alpha',\beta',\gamma',\delta',\epsilon',
d',h',i',\phi',\psi',\eta',\theta',\kappa')
\]
in the fifteen nonconstant monomials
\[
h,d,dh,c,ch,cd,cdh,c^2,c^2h,c^2d,c^2dh,
c^3,c^3h,c^3d,c^3dh.
\]
This defines a \(16\times15\) matrix M over \(k[A,B,C,D,E,G,J]\).

## 2. Theorem UF-062A.1

The ideal generated by the sixteen maximal minors of M is exactly
\[
I_{15}(M)=(E^{15}).
\]
More precisely, the only nonzero maximal minor is the one obtained by omitting the epsilon-prime row, and that minor equals \(E^{15}\).

**Consequences.**
- The rank-15 locus on this slice is exactly the principal open set \(D(E)\).
- The set-theoretic rank-drop locus is \(V(E)\).
- The scheme defined by the maximal minors is the nonreduced divisor \(15V(E)\), with ideal \((E^{15})\).

The computation is exact over \(\mathbb F_2[A,B,C,D,E,G,J]\), not a numerical sample.

## 3. Theorem UF-062A.2 — generic rank on the rank-drop divisor

After imposing E=0, the matrix has rank exactly 11 over the rational function field
\[
\mathbb F_2(A,B,C,D,G,J).
\]
An explicit nonzero 11-by-11 minor uses target rows
\[
(c',a',b',\alpha',\beta',d',h',i',\phi',\psi',\eta')
\]
and nilpotent columns
\[
(h,d,dh,c,ch,cd,cdh,c^2,c^2h,c^3,c^3h).
\]
Its determinant is
\[
C^3D^4J^4.
\]
A symbolic row reduction over the rational function field gives the matching upper bound 11. Hence the generic rank along E=0 is 11.

This does not say every point of E=0 has rank 11: special subloci may have smaller rank. Nor does it identify the full-family rank-drop locus.

## 4. Verification

The exact symbolic verifier is tools/fold_char2_affine_rank_drop_slice.py. It uses SymPy polynomial arithmetic over F_2, computes all sixteen 15-by-15 minors, checks that their ideal is (E^15), and computes the generic rank after setting E=0. Install SymPy with the command python -m pip install sympy before running it.

## 5. Remaining UF-062 work

1. Enlarge the slice to arbitrary reduced affine coefficients a,b,i and determine the full maximal-minor ideal.
2. Determine all lower-rank strata inside E=0, including the loci C=0, D=0, and J=0 and their intersections.
3. Compare the coefficient-matrix rank-drop scheme with the universal conjugation pullback kernel. They are different constructions and must not be conflated.
4. Compute the largest Hopf ideal contained in the orbit-image kernel.
