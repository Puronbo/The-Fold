# UF-003 — The Geometric Fold Generator Catalogue

**Question.** What is the natural primitive operation catalogue when allowed operations are derived from The Fold's actual geometry rather than chosen as arbitrary integer powers?

**Answer.** The repository defines a geometric fold as a reflection (an involution), and a twist as the composition of two reflections. For a finite planar closure of order m, the primitive operations are therefore the available crease reflections. Selecting the fewest creases that generate a desired dihedral subgroup is a gcd/set-cover problem.

This note also separates the geometric operation system from the arithmetic Frobenius-power model used by UFSF/UF-002. They share a cyclic-group order formula, but they are not the same action.

## 1. What the repository actually permits

| Object | Definition / law | Mathematical role |
|---|---|---|
| Scale | g_k(P)=P₀+k(P−P₀); g_a∘g_b=g_(ab) for nonzero scalars | Similarity / scale-phase action |
| Geometric fold | Reflection σ_H, with σ_H²=I and det σ_H=−1 | Primitive involution |
| Twist | σ_(H₂)∘σ_(H₁)=R(2α) | Composite rotation, made from two folds |
| Finite closure | (σ₂σ₁)^m=I, where m=π/α | Dihedral group D_m of order 2m |
| Collapse | g_0(P)=P₀ | Constant, noninvertible map; not a group generator |
| Sheet fold | F(x,y)=(x,|y|), F²=F | Idempotent quotient map; not the reflection used to generate twists |

These distinctions are explicit in Fold/Basic.lean, Fold/Scale.lean, the-fold-composition.md, the-fold-closure.md, and the-fold-creation.md.

The composition note distinguishes the reflection σ from the physical sheet-fold map F: only the reflection composes into a rotation. The twist is a composite of two primitive folds. Therefore, if we count primitive geometric operations, the catalogue should list crease reflections, not arbitrary powers r.

Positive real scaling is continuous and commutes with planar rotations/reflections; it changes size but does not generate a new finite dihedral subgroup. The zero scale collapses all observable points and is excluded from an invertible symmetry group.

## 2. Encode the finite geometric closure

Fix m≥2 and let ζ_m=e^(2πi/m). The m reflection axes are indexed by j in Z/mZ, with line angle φ_j=jπ/m. Reflection in that line is

\[
\boxed{\sigma_j(z)=\zeta_m^j\,\overline z.}
\]

Every reflection is an involution, σ_j²=I. Composing two reflections gives

\[
\boxed{\sigma_b\circ\sigma_a(z)=\zeta_m^{b-a}z=R^{b-a}(z),\quad R(z)=\zeta_m z.}
\]

Thus the rotation exponent is the difference of crease indices, taken additively modulo m. It is not an arbitrary power parameter attached independently to each fold.

The full group is

\[
D_m=\langle R,\sigma_0\mid R^m=1,\ \sigma_0^2=1,\ \sigma_0R\sigma_0=R^{-1}\rangle,
\]

of order 2m.

## 3. The subgroup generated by a selected crease set

Let A be the catalogue of available crease axes in Z/mZ, and choose a nonempty subset J⊆A. Fix an anchor a₀∈J and define

\[
g_J=\gcd\bigl(m,\{j-a_0:j\in J\}\bigr).
\]

The additive subgroup generated by the differences j−a₀ in Z/mZ is g_J Z/mZ. Its order is m/g_J. Since every pair of selected reflections gives a rotation by one of these differences, the group generated by the chosen reflections has

\[
\boxed{q_J=m/g_J,\qquad |\langle\sigma_j:j\in J\rangle|=2q_J.}
\]

For one selected axis, g_J=m, so the generated group is just one reflection, of order two. With no selected axes, the generated group is the identity group.

### Theorem 1 — Geometric subgroup criterion

For a target divisor q|m, the selected crease set J generates a dihedral subgroup with rotation subgroup of order exactly q if and only if

\[
\boxed{\gcd\bigl(m,\{j-a_0:j\in J\}\bigr)=m/q.}
\]

In particular, the selected creases generate the full D_m if and only if their axis differences generate all of Z/mZ, equivalently the gcd is 1.

**Proof.** The rotations obtained by composing pairs are R^(j−a₀). In the cyclic rotation group generated by R, the subgroup generated by the difference residues is the subgroup of multiples of their gcd with m; its order is m/g_J. The selected reflection supplies the other coset, so the whole generated subgroup has twice the rotation-subgroup order. ∎

## 4. Minimum number of available creases is set cover

Fix a target rotation order q|m and put g=m/q. Choose an anchor axis a∈A. Every other selected axis b must satisfy b≡a (mod g), otherwise the gcd of all differences could not equal g. Define the normalized difference

\[
x_b=(b-a)/g\pmod q.
\]

The target criterion becomes gcd(q,{x_b})=1. This holds exactly when, for every prime ℓ dividing q, at least one selected candidate has ℓ not dividing x_b.

For a fixed anchor a, candidate axis b therefore covers

\[
C_{a,b}=\{\ell:\ell\text{ prime},\ \ell\mid q,\ \ell\nmid x_b\}.
\]

Selecting the smallest number of additional axes whose cover sets contain every prime divisor of q is a finite Set Cover instance. Minimize over all possible anchors.

### Theorem 2 — Exact minimum-axis reduction

For fixed m, target q|m, and finite allowed-axis catalogue A, the minimum number of reflections generating the target dihedral subgroup is

\[
\boxed{
1+\min_{a\in A}\operatorname{SC}
\left(
\{\ell:\ell\text{ prime},\ell\mid q\},
\{C_{a,b}:b\in A,\ b\ne a,\ b\equiv a\pmod g\}
\right),
}
\]

where SC is the minimum set-cover cardinality. For q=1, the prime universe is empty and a single reflection is sufficient.

**Proof.** The anchor contributes one reflection. Every other chosen axis must be in the same residue class modulo g, and Theorem 1 requires their normalized differences to have gcd one with q. This is equivalent to covering each prime divisor of q with at least one nondivisible normalized difference. Taking the minimum over anchors considers every possible selected set. ∎

## 5. Worked examples

### 5.1 A complete regular catalogue

If all m axes are available, adjacent axes 0 and 1 differ by 1, so gcd(m,1)=1. Two reflections generate the full D_m. Two is minimal because one reflection cannot generate a nontrivial rotation.

For m=12, the minimum full-generator set is {0,1}, and the generated group has order 24.

### 5.2 A sparse catalogue where three folds are necessary

Let m=30 and A={0,6,10,15}. No pair of available axes generates the full D_30:

| Pair | Difference | gcd(30,difference) | Rotation order |
|---|---:|---:|---:|
| {0,6} | 6 | 6 | 5 |
| {0,10} | 10 | 10 | 3 |
| {0,15} | 15 | 15 | 2 |
| {6,10} | 4 | 2 | 15 |
| {6,15} | 9 | 3 | 10 |
| {10,15} | 5 | 5 | 6 |

But J={6,10,15} has differences 4 and 9, and gcd(30,4,9)=1. These three axes generate D_30, of order 60. The minimum is therefore three primitive folds for this sparse catalogue.

### 5.3 Generating a proper subgroup

For m=30, the axes {0,5,10,15,20,25} contain a pair separated by 5. Since gcd(30,5)=5, two folds generate a rotation subgroup of order 6, hence a dihedral subgroup of order 12.

## 6. What is and is not a geometrically natural catalogue?

- **Primitive catalogue:** available reflection axes/creases A. This follows the repository's rule that a twist is two folds.
- **Derived operations:** rotations R^δ=σ_bσ_a. They are composites; counting them as primitive is a different cost model and must be declared separately.
- **Scales:** positive g_ρ form a continuous multiplicative family. They change size and commute with the orthogonal finite subgroup; they do not contribute new rotation axes.
- **Collapse:** g_0 is a constant map, not an invertible symmetry. Admitting it in an invariant problem erases every observable distinction.
- **Sheet fold:** F(x,y)=(x,|y|) is idempotent, not an involution. It is a quotient map, not a generator of the dihedral rotation group.
- **Closure order:** in abstract planar geometry every rational angle can give a finite D_m. If the object must preserve a periodic planar lattice, the repository's crystallographic restriction leaves only m∈{1,2,3,4,6}. These are different assumptions.

## 7. Boundary with UFSF and arithmetic power transitions

The earlier UFSF signature uses d=ord_m(p), where p is a prime not dividing m and p belongs to (Z/mZ)^×. This is the order of an arithmetic Frobenius element in

\[
\operatorname{Gal}(\mathbb Q(\zeta_m)/\mathbb Q)\cong(\mathbb Z/m\mathbb Z)^\times.
\]

The UFSF power transition p↦p^r is iteration/powering of that arithmetic automorphism. It is a valid algebraic spectral operation, but it is **not automatically one of the geometric Fold transformations**.

The geometric action is different:

- A geometric rotation sends z↦ζ_m^δ z; on roots ζ_m^a it shifts the exponent a↦a+δ.
- Arithmetic Frobenius sends ζ_m^a↦ζ_m^(pa); it multiplies the root exponent by p.
- A geometric reflection sends z↦ζ_m^j conjugate(z); it reverses orientation and conjugates a rotation to its inverse.

Thus the two systems share the general cyclic-group formula

\[
\operatorname{ord}(x^r)=\operatorname{ord}(x)/\gcd(\operatorname{ord}(x),r),
\]

but the elements x, the acting groups, and the transformations are different. A homomorphism or representation connecting the Frobenius action to the geometric Fold action would have to be supplied and proved; it is not part of the current repository model.

This correction keeps UF-002 useful as an **arithmetic spectral power-operation model**, while UF-003 is the actual geometry-derived generator problem.

## 8. Executable verification and formalization

The standard-library script tools/fold_geometric_generators.py:

1. Implements the dihedral composition law on pairs (orientation parity, rotation index).
2. Computes the generated subgroup from a selected set of reflection axes.
3. Verifies the gcd formula against explicit finite-group closure.
4. Solves the minimum-axis problem by set-cover dynamic programming for each anchor.
5. Compares the dynamic program with brute force for every axis catalogue and divisor target for 2≤m≤9.

The bounded checks reported by the current script are:

| Check | Passed |
|---|---:|
| Dihedral composition pairs | 1,136 |
| GCD formula vs explicit group closure | 1,020 |
| Minimum-axis DP vs brute force | 3,186 |
| Worked sparse/full/proper-subgroup examples | 3 |

These are finite implementation checks, not replacements for Theorems 1 and 2.

Lean formalization should build on the existing dependency-free Fold involution in Fold/Basic.lean. A later Mathlib-backed extension can formalize the cyclic subgroup order and gcd characterization. The geometric generator theorem itself can be represented first over ZMod m, without importing the cyclotomic polynomial layer.

## 9. Result and next question

UF-003 supplies the missing operation catalogue: **the primitive operations are available crease reflections; twists and rotations are their composites.** Their subgroup generation is controlled by gcds of crease-index differences, and the minimum catalogue problem reduces to set cover over prime divisors of the target rotation order.

The next genuine Fold-specific problem is to derive the allowed crease catalogue A from the geometry or application being modeled. Once A is specified, the minimum generator set is exactly computable. The arbitrary exponent catalogue of UF-002 should not be substituted for A without an explicit mathematical identification.
