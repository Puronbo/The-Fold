# UF-001 — The Universal Fold Invariant

**Question.** Given a specified family of Fold operations, what information is unchanged by every allowed operation?

**Status.** The quotient theorem and finite arithmetic spectral-state result below are proved. The first is a standard universal property; the second is an elementary cyclic-group classification. The finite power transitions act on a modular unit/Frobenius element; they are not automatically geometric crease reflections. The geometry-derived generator catalogue is developed separately in the-fold-geometric-generators.md (UF-003). Neither result is claimed as a new theorem about prime distribution.

## 1. General answer: the orbit quotient

Let \(X\) be a set and let \(\mathcal F=\{F_i:X\to X\}\) be the allowed operations. A function \(J:X\to Y\) is invariant when \(J(F_i(x))=J(x)\) for every \(i,x\).

Let \(\sim_{\mathcal F}\) be the smallest equivalence relation containing all pairs \((x,F_i(x))\). It connects states joined by a finite undirected path of allowed operation edges. Let \(q:X\to X/{\sim_{\mathcal F}}\) be the quotient map.

### Theorem 1 — Universal invariant theorem

A function \(J:X\to Y\) is invariant under every allowed operation if and only if it factors uniquely through \(q\):
\[
J=\bar J\circ q
\]
for a unique \(\bar J:X/{\sim_{\mathcal F}}\to Y\).

**Proof.** Invariance makes \(J\) equal at the endpoints of every generating edge. Equality is symmetric and transitive, so \(J\) is constant on each equivalence class. Hence \(\bar J([x])=J(x)\) is well-defined. Conversely, a function factoring through \(q\) is constant on every generating edge. Uniqueness follows from surjectivity of \(q\). \(\square\)

The quotient class is the complete common invariant: every other common invariant is a function of it. This is the standard quotient universal property.

### Theorem 2 — Total-collapse obstruction

If the allowed operations include a constant map \(C(x)=c\), every common invariant is constant:
\[
J(x)=J(C(x))=J(c).
\]
A retained reference can survive only if it is explicitly included in an augmented state and preserved by collapse. That is side information, not an inverse of the constant map on the observable coordinate.

## 2. Finite arithmetic spectral state space

The power map a↦a^r below is an operation on an arithmetic modular unit (equivalently, on its Frobenius automorphism). It should not be read as a physical Fold reflection or as a geometric twist. A direct geometric primitive is a reflection σ_H; a rotation is generated by composing two such reflections. The distinction and the corresponding minimum crease-generator problem are proved in the UF-003 note.

Fix rotation moduli \(m_1,\ldots,m_t\), all at least 2. For a unit \(a\) modulo \(m\), define
\[
d_m(a)=\operatorname{ord}_m(a),\qquad
\tau_m(a)=
\begin{cases}
1,&-1\in\langle a\rangle,\\
0,&-1\notin\langle a\rangle.
\end{cases}
\]
A spectral signature is \((d,\tau)\); validity requires \(\tau=1\Rightarrow 2\mid d\). A joint state is a tuple \(S=((d_j,\tau_j))_{j=1}^t\). An optional orientation bit may be appended.

For a positive integer \(r\), the modular power map \(a\mapsto a^r\) induces
\[
\boxed{\Pi_r(d,\tau)=
\left(\frac{d}{\gcd(d,r)},
\tau\cdot\mathbf1_{\ d/\gcd(d,r)\ {\rm even}}\right).}
\]
The order formula is the standard order-of-a-power formula. If \(\tau=1\), the cyclic group generated by \(a\) has a unique element of order two, namely \(-1\); the subgroup generated by \(a^r\) contains it exactly when its new order is even. If \(\tau=0\), no subgroup of the original cyclic group can contain \(-1\).

The transitions compose:
\[
\Pi_a\circ\Pi_b=\Pi_{ab}.
\]
Turning toggles an optional orientation bit. Inversion \(a\mapsto a^{-1}\) preserves \(d,\tau\), since it does not change the generated cyclic subgroup.

## 3. The finite-family invariant

Let \(R=\{r_1,\ldots,r_s\}\) be a finite set of positive exponents, and put
\[
L=\operatorname{lcm}(r_1,\ldots,r_s),
\]
with \(L=1\) for the empty family.

Define the prime-to-\(L\) core of \(d\) as its largest divisor coprime to \(L\):
\[
\operatorname{core}_L(d)=\prod_{\ell\nmid L}\ell^{v_\ell(d)}.
\]
Define \(\widehat\tau_L(\tau)=\tau\) when \(L\) is odd, and \(0\) when \(L\) is even. Set
\[
\boxed{
I_R(S)=\big((\operatorname{core}_L(d_j),\widehat\tau_L(\tau_j))\big)_{j=1}^t.
}
\]
When turning is allowed, the optional orientation bit is omitted.

### Theorem 3 — Invariance

For every \(r\in R\), \(I_R(\Pi_r(S))=I_R(S)\); it is also invariant under turning.

**Proof.** Every prime dividing \(r\) divides \(L\). The power transition removes some powers of primes dividing \(r\) and changes no exponent at primes outside \(L\); the prime-to-\(L\) core is therefore unchanged. If \(L\) is odd, every allowed exponent is odd, so order parity and \(\tau\) are preserved. If \(L\) is even, the invariant records zero in the turning coordinate. Turning changes only the omitted orientation bit. \(\square\)

### Theorem 4 — Completeness on the abstract spectral-state graph

The fibers of \(I_R\) are exactly the connected components generated by all \(\Pi_r\), \(r\in R\), and turning:
\[
S\sim_R S'\iff I_R(S)=I_R(S').
\]

**Proof.** Invariance gives one direction. Let \(E=\prod_{r\in R}r\), taking \(E=1\) when \(R\) is empty. Its prime support is the same as that of \(L\). Applying each allowed transition once is \(\Pi_E\). Repeated \(\Pi_E\) removes every prime-power component of each order supported on a prime dividing \(L\), leaving \(\operatorname{core}_L(d_j)\). If \(L\) is even, the 2-primary component is removed and \(\tau\) becomes zero; if \(L\) is odd, \(\tau\) is preserved. A turn aligns any optional orientation bit. Thus each state reaches the canonical representative encoded by \(I_R\). States with equal invariants reach the same representative and are connected. \(\square\)

This is completeness for the **abstract spectral-signature state graph**, not unique identification of original residues or primes.

### Corollaries

A state is fixed by every \(\Pi_r\), \(r\in R\), exactly when \(\gcd(d_j,L)=1\) for every component.

Put \(E=\prod_{r\in R}r\). Repeated full rounds \(\Pi_E\) stabilize an order \(d\) after
\[
K(d,E)=\max_{q\mid E}\left\lceil\frac{v_q(d)}{v_q(E)}\right\rceil,
\]
with maximum zero if \(d\) and \(E\) are coprime. For a joint state take the maximum over components.

## 4. No-go boundaries

If every positive power \(\Pi_r\) is allowed, choose \(r=\operatorname{lcm}(d_1,\ldots,d_t)\) for a given state. Every component becomes \((1,0)\). Thus every common invariant on the **unoriented** spectral state space is constant. If an orientation bit is stored, power maps alone preserve it; adding the turn operation identifies the two orientations as well.

A total observable-collapse map likewise forces every observable-only invariant to be constant. Retained reference/history survives only if it is an explicit preserved coordinate.

## 6. What this does and does not establish

| Claim | Status |
|---|---|
| Every operation family has an orbit quotient | Standard universal-property theorem |
| Every common invariant factors through it | Proved in Theorem 1 |
| Total collapse forces observable invariants to be constant | Proved in Theorem 2 |
| Finite spectral power families have closed-form invariant \(I_R\) | Proved in Theorems 3–4 |
| \(I_R\) uniquely identifies the original prime | False in general; collisions occur |
| The invariant gives a prime-generation method | Not established |
| The invariant proves RH or locates zeta zeros | Not established |

## 7. Lean 4 implementation boundary

The repository's root project deliberately imports only Init. Preserve that boundary. The general quotient theorem can be formalized in a dependency-free module; finite-group order and cyclotomic facts belong in a separate Mathlib-backed package.

Implementation targets:
1. Define reachability as the reflexive, symmetric, transitive closure of operation edges.
2. Define invariance under each allowed operation.
3. Prove equality along reachability.
4. Construct the quotient and descend invariant functions with Quotient.lift.
5. Formalize the order-of-a-power and finite-family core lemmas in the separate Mathlib package.

These are specifications, not compiler-verified Lean code. Lean/Lake must be available and the statements checked against the pinned toolchain before adding them to the build.

## Conclusion

The answer to UF-001 is conditional: the complete invariant is the orbit quotient of the chosen operations; total observable collapse makes it constant; a finite spectral power family has the explicit representative \(I_R\); and allowing all positive powers makes the unoriented invariant constant.

> Specify the admissible Fold operations, compute their orbit quotient, and identify exactly which information survives that quotient.

This is the precise mathematical version of “what remains after every allowed fold?”
