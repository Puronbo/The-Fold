# Stage 26 — Structural Equivalence and Quotient Spaces

## Purpose

Stage 25 supplied a finite group action on a finite state set. Stage 26 constructs the corresponding orbit quotient and tests whether a supplied binary relation can be meaningfully transferred to that quotient.

## Mathematical construction

Let a finite group \(G\) act on a set \(X\). Define

\[
x\sim_G y \iff \exists g\in G:\ g\cdot x=y.
\]

This is an equivalence relation:

- Reflexivity follows from the identity element.
- Symmetry follows from the inverse of each group element.
- Transitivity follows from closure under composition.

Its equivalence classes are the orbits \(Gx\), and the quotient is

\[
X/G=\{Gx:x\in X\}.
\]

The quotient records which states are related by the selected transformations. It does not assert that members of an orbit are literally identical in every other task or representation.

## Canonical representatives

The implementation chooses the first state in each orbit according to the caller-supplied state order. This makes the output deterministic for a fixed input ordering, but the representative is not intrinsic: reordering the input can change it while leaving the orbit partition unchanged.

Class indices follow the order in which their first representatives occur.

## Relation descent: two distinct tests

For a supplied binary relation \(R\subseteq X\times X\), diagonal invariance means

\[
(x,y)\in R\implies(gx,gy)\in R
\quad\text{for every }g\in G.
\]

This applies the same group element to both endpoints. It is not sufficient to define a relation on \(X/G\).

A quotient relation is well-defined only if membership is constant on every product of orbits:

\[
\forall C,D\in X/G,\quad
\bigl[(x,y)\in R\bigr]
\text{ has the same truth value for all }(x,y)\in C\times D.
\]

When this stronger condition holds, define

\[
(C,D)\in R_{Q}\iff (x,y)\in R
\quad\text{for any }x\in C,\ y\in D.
\]

The implementation checks this condition exhaustively and emits no quotient relation if it fails.

### Counterexample: diagonal invariance is insufficient

Take \(X=\{0,1\}\), with the group generated by the swap \(0\leftrightarrow1\), and let \(R\) be equality:

\[
R=\{(0,0),(1,1)\}.
\]

The diagonal swap preserves \(R\). But there is only one orbit \(C=\{0,1\}\), and \(C\times C\) contains both related pairs, such as \((0,0)\), and unrelated pairs, such as \((0,1)\). Thus \(R_Q\) is not well-defined.

## Information accounting

The report gives

\[
|X|,\quad |X/G|,\quad |X|-|X/G|.
\]

The final quantity counts how many state labels are removed by orbit compression. It is a cardinality difference, not Shannon entropy, physical information, or a universal measure of information loss.

The class sizes and state-to-class map retain the partition structure, while the quotient alone forgets distinctions within each orbit.

## Implementation

- **agi/quotient_spaces.py**: immutable quotient report and constructor.
- **agi/test_quotient_spaces.py**: exact finite regression tests.
- **construct_orbit_quotient(states, transformations, relation=None)**: validates through the Stage 25 group-action analyzer, constructs orbits, selects deterministic representatives, and checks relation descent.

## Limits

The algorithm is finite and exhaustive over explicitly supplied states, permutations, and relations. It does not discover symmetries from raw data, choose which distinctions matter for a task, infer a useful quotient automatically, or establish that an abstraction is appropriate for a physical system. A quotient is only as meaningful as the action and equivalence relation supplied.

## Status

This stage establishes a correct finite construction and a stricter relation-descent check. It is a mathematical component for abstraction and concept learning, not evidence that general intelligence or AGI has been achieved.
