# The Fold: the loop from the first point to now

## What this note is

This is the closing note. It adds no mechanism, no theorem, and no new exact transfer. It retells the
corpus as one loop: from the initial point and its boundary, through the fold and the complexified
scale, through the cosmic history, to the CMB and the observer who reads it.

The loop is a **closure of description**, not a claim that the universe is a literal time loop. The
physical loop is not established; the descriptive loop is exact as an inference. The CMB enters as a
**rhyme**, because the corpus contains no CMB derivation. The exact physics is on the CMB side; the
exact algebra is on the Fold side; the mapping is not a proof.

The rule is the same as in `the-fold-problems.md`:

- **exact** — the Fold's object is the problem's object, re-described;
- **rhyme** — the same shape, different objects;
- **false friend** — the same symbol, different meaning.

A rhyme written as a proof is the one error that matters.

## The start: two faces, not one object

The Fold's description starts with two things that are not the empty set:

```
P₀ : the unique point fixed by every g_k ,  g_k(P₀) = P₀
k = 0 : the boundary of the group ,  g₀(P) = P₀ for every P
```

`P₀` is the initial state: the datum, the zero object, the point with `n` ambient directions. Its
initial form is `Dg₀ = 0`, the null form `(0,0,n)`. It is not the empty set: the empty set has no
tangent space, so its inertia is empty, not `(0,0,n)`.

`k = 0` is not a member of the group. The group is defined for `k ≠ 0`; `k = 0` is its boundary, the
total collapse. The hole field calls this excluded point the puncture:

```
ω = dk/k ,  Res_0 ω = 1 ,  Res_∞ ω = −1 ,  ∮_{|k|=r} ω = 2πi
η = Im ω = dθ ,  ∮ η = 2π ,  H¹_dR(ℂ*) = ℝ[η]
```

The point and the boundary are not the same object. The point is in the space; the boundary is
outside the group. The "puncture" is the hole field's name for the excluded point; the initial note's
name for it is the boundary of the group. The cosmological reading — "the universe begins as a point
with a puncture" — is a rhyme, not a derivation.

The empty product is `1`; the empty sum is `0`; the zero-parameter stratum `(ℂ*)^0` is the point. The
start is a structured absence, not `∅`.

## The first operation and the first split

The pipeline orders the stages:

```
point → scale → fold → twist → closure → horizon → observer → point
```

The first **operation** is the scale: `g_k(P) = P₀ + k(P − P₀)`, `det g_k = kⁿ`. For `k = 0`, every
point collapses to `P₀`; the scale stage's zero is the vertex, with inertia `(0,0,n)`. The first
**split** is the fold:

```
σ_H : ℝⁿ → ℝⁿ ,  σ_H² = I ,  σ_H ≠ I
crease = ker(σ_H − I) ,  dim = n−1
signature = (n−1, 1, 0)
```

The crease is the fixed set; the normal is the `−1` eigenspace. The fold does not collapse; it
distinguishes. The closure `m = π/α` and the crystallographic restriction `m ∈ {1,2,3,4,6}` are the
discrete ways the fold can close.

The distinction matters for the loop: the scale is an operation without a period; the fold is a split
without a motion. The period arrives only when the scale is complexified.

## The real scale and the complex twist

The real scale action is a homothety:

```
g_k : x ↦ kx ,  k > 0
det g_k = kⁿ
```

It has no period. A homothety does not return; it only grows or shrinks. The logarithm turns it
additive:

```
h = ln k ,  g_a ∘ g_b = g_{ab} ,  ln(ab) = ln a + ln b
```

The complexified scale is a model, not the original action:

```
k = e^{t+iθ} ∈ ℂ*
ω = d ln ρ + i dθ
Re ω = d ln ρ   (scale)
Im ω = dθ       (twist)
```

The twist `θ` has period `2π`; the scale `ρ` does not. The `2π` is the period of the rotation, not of
the homothety. The closure `m = π/α` is conditional: it closes when `α/π` is rational; irrational
`α/π` never closes. The crystallographic restriction applies to the closure of a lattice, not to the
continuous scale.

So the "scale loop" is not `g_k` with a period. It is the **complexified scale** with a twist period,
plus a conditional closure. This is the precise correction to the tempting sentence "the scale action
is a loop of period `2π`." The `2π` belongs to the twist register, not the real scale.

## The CMB as bookmark

The CMB is a 2-sphere of sections: `T(n̂)`, `Q(n̂)`, `U(n̂)`. The angular power spectrum is

```
C_ℓ = (1/(2ℓ+1)) Σ_m |a_ℓm|²
```

and the acoustic peaks sit at `ℓ_n ≈ nπD/r_s`. The spectral index is a log derivative:

```
n_s − 1 = d ln P / d ln k
```

The polarization is a spin-2 field; E/B is its parity decomposition; a rotation by `β` is cosmic
birefringence. The last-scattering surface is a horizon. The topology, if nontrivial, can produce
matched circles; the holonomy around a non-contractible loop is a period. The zero contours of the map
are excursion-set boundaries; their Euler characteristic is a topological invariant.

The Fold reads four of these:

- the scale, through `ℓ` and `r_s`;
- the log derivative, through `n_s − 1`;
- the twist, through the polarization angle;
- the horizon, through the last-scattering surface.

It does not read the volume, the later history, the dark-sector microphysics, or the future. The CMB is
a boundary condition, not a recording. The bookmark is a new image; the corpus had no CMB note before
this one. The image is a rhyme.

## The observer and the closure

The observer is a measurement aperture `(d,w)`, not a transformation. It does not create the zero; it
is the zero's last witness. So the loop does not close because the observer creates it. It closes
because the description returns to its object:

- the first loop writes the pattern in the CMB;
- the second loop writes the observer;
- the observer reads the CMB;
- the reading is the closure.

The `∮ dk/k = 2πi` is the period of the description, not the age of the universe. The loop is a
**hermeneutic circle with a physical anchor**: the same scale action that wrote the pattern is the one
the observer uses to read it. The observer is the witness, not the author.

## What the loop is not

- not a cyclic universe; there is no evidence for a bounce or a previous aeon;
- not a closed timelike curve; there is no evidence for causality violation;
- not a proof of creation from nothing; "nothing" is a boundary condition, not a state;
- not a theory of everything; the laws are assumed, not derived;
- not the claim that the universe is literally one object and a hole; that is an image, not a theorem;
- not an exact CMB derivation; the CMB enters as a rhyme, and the exact physics is standard cosmology.

## The one sentence

**The Fold begins with a point and a boundary, turns the scale into a fold and a twist, stretches the
small into the large, freezes the pattern at the CMB, and closes when an observer reads the bookmark by
the same scale action that wrote it — not because the observer creates the loop, but because the
