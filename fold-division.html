The point at fraction t is again a homothety, of factor φ = 1 + t(k−1). It collapses exactly when k = (t−1)/t, so each division point owns one value of k. The midpoint owns k = −1; the quarter point owns k = −3, whose midpoint map is g−1 — the fold itself. Points t and 1−t own reciprocal values, and the only k that no division point owns is k = 1, the identity.
