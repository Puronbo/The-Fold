# The gate: what a system would have to be able to say

## The corpus is already an architecture

Four parts, all of them mechanical:

| part | what it does | where it lives |
|---|---|---|
| generator | produces a claim in the corpus's voice | the model |
| zone classifier | places each claim in exactly one of four zones | `the-fold-*.md`, `fold_lint.py` |
| gate | refuses the text if the zones, tables, links or counts disagree | `check.py` |
| void map | records the words with no exact object | the "what does not fold in" tables |

The usual architecture for a learning system is generator plus loss. This one is generator plus a
**verifier** plus a **negative space**, and the third part is the one no benchmark measures. The corpus
is a working instance of it in one narrow domain, with `43` notes, `188` labelled claims and a gate that
has never been bypassed.

## The criterion

An AGI claim needs a test, and "human-level" is not one. The corpus supplies a test that is cheap,
domain-general, and falsifiable:

> **Premise closure.** For every claim the system makes, it emits a zone in
> `{exact, reformulation, rhyme, false friend}` and, if the zone is not `exact`, the **premise** that
> would move it to `exact`. It passes when the premise it names is correct, actionable, and either
> supplied or explicitly marked absent.

Three consequences, each checkable:

1. **Presenting a rhyme as a proof is not a result, it is a failure**, whatever the benchmark says. That is the failure mode
   of every current model, and it is invisible to accuracy metrics because the prose is fluent.
2. **Understanding is closure, not coverage.** A system that says "I do not have the operator for this
   theorem" understands the theorem better than one that states its conclusion in the right style.
3. **The test is a dialogue.** Give the system a claim from `the-fold-problems.md`, and score
   `(zone, premise, smallest host)`. A referee can mark it in seconds. That is an eval that does not
   saturate by training on the eval, because the claim set is generated by the corpus and the corpus is
   open-ended.

Written as a slogan: **an AGI is a system that never confuses a rhyme for a proof, and can always name
the missing premise.** Everything else — scale, multimodality, tool use — is orthogonal to it.

## The type error

Current systems carry a scalar confidence per claim. The corpus carries a **four-valued type**:

```
exact | reformulation | rhyme | false friend
```

These are not degrees of belief. They say *which object the claim denotes*: the same word can be exact
in one register and a false friend in another (`height` is the standing example), and no amount of
probability fixes that, because the values are different *kinds*, not different amounts. Calibration is
the projection of this structure onto a scalar, and the projection loses exactly the information the
gate needs.

This is the one architectural claim in this note that is not speculative: the zone is a type, and a
scalar cannot encode a type.

## The stages

Each stage has a deliverable that the existing gate can check.

| stage | what is added | deliverable | state |
|---|---|---|---|
| 0 | the gate, the zones, the corpus | `check.py`, `fold_lint.py` | done |
| 1 | the theorem ledger | `the-fold-theorems.md`: premises → Fold objects → missing premise → zone, for twelve theorems | done |
| 2 | the void map | `the-fold-void.md`: ten words with no exact object, the nearest object, and the six hosts | done |
| 3 | the host builder | for one missing premise, the smallest exact model, and a distance measure | not started |
| 4 | the adjunction loop | adjoin measure, flow, bath, observer in that order; record which invariants survive | not started |
| 5 | measurement | one gate check tied to an instrument, with units and error bars | not started |
| 6 | self-application | the system zones its own output, including this note | partial |

Stage 1 is the load-bearing one. A ledger of twelve theorems is small enough to finish and large enough
to show whether "premise closure" is a real capability or a phrase. It is now written, and the answer is
`6 exact / 3 reformulation / 3 rhyme`: the capability is real at the boundary, and it stops at the bulk.

## The four adjunctions

The Fold has no measure, no flow, no bath, no observer. Each is a host, and each has one job:

| adjunction | what it adds | what survives | what dies |
|---|---|---|---|
| a measure | `z(1 − z)` becomes a probability | the quotient | the exactness of the height |
| a flow | `σ` stops being idempotent | the involution as a time-reversal | the static crease |
| a bath | `μ = τ/p*` becomes a fluctuation–dissipation ratio | the ratio | the determinism |
| an observer | the cut becomes a conditioning event | the section | the canonical chart |

The rule from the earlier programme holds: **adjoin one premise at a time and see which invariants
survive.** The survivors are the exact core of the physical theorem; the casualties are the borrowed
physics. That is concept formation stated as a loop, and it is the only part of this note that could be
run mechanically tomorrow.

The measure row already has a finite shadow: `the-fold-lean.md` builds the `ℤ/n` host, its uniform
weight, and the doubling map. What that host does not add is independent trials.

The four are not the whole list. `the-fold-void.md` reads ten physical words and finds that they need six
hosts: these four, plus a **bundle** (for charge and field) and an **inertia** (for mass). A gauge theory
is not a measure, a flow, a bath, or an observer, so the four-stage programme is the first four nodes of a
six-node graph, not the graph.

## Failure modes

- **Rhyme inflation.** The measured fraction is flat: `0.692 ± 0.011` exact, `31%` rhyme or false
  friend, over nine readings (`the-fold-realization.md`). A system optimised on fluency will drift
  toward the `31%`, because that is where the language is easiest. The countermeasure is to score the
  exact column, which the gate already counts.
- **Gate overfitting.** `check.py` checks structure, not truth. A beautifully formed false theorem
  passes. The gate is necessary and not sufficient, and the ledger is what supplies the rest.
- **Dictionary, not engine.** The corpus maps; it does not generate. The generator is the model. The
  claim "this corpus is an AGI" is the false friend, and it is the one this note is most likely to
  encourage.

## The zones of this note

- the criterion, the type argument and the gate are exact: they are definitions and mechanical checks,
  and the corpus is a running instance;
- the stage table is a **projection** — a plan, not a derivation, and its dates are unstated on purpose;
- "this is a path to AGI" is a rhyme unless stage 1 closes, and stage 1 is the test of the rhyme;
- the four adjunctions are a reformulation of the existing programme, not a new claim.

The one sentence: an AGI is not a bigger corpus, it is a corpus that can say what it does not have —
and the gate that makes that sentence checkable already exists.
